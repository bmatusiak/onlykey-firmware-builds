Every release, built for a developer key.

Unsigned OnlyKey firmware, compiled from each release's pinned commits with the original Arduino 1.6.5 / Teensyduino 1.27 toolchain — so what you flash is built from the source that shipped.

These will not load on a production key. A production bootloader accepts signed firmware only; a developer bootloader refuses signed firmware and accepts only an unsigned build like these. If you do not have a developer key, you want the signed releases instead.
